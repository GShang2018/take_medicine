# 吃药提醒 · Android 版

把原来的网页版服药日历做成了一个可以直接安装的安卓 App：到点用**闹钟**方式响铃（**锁屏/息屏时会自动点亮屏幕并显示通知，解锁使用手机时可弹出底部提醒卡片**），同时可以把服药计划写进**系统日历**。支持为家人建立多个账户，每个账户有自己的药、订阅链接和系统日历，互不混淆。

- 包名：`com.medremind.app`
- 版本：1.5.11（versionCode 25）
- 支持：Android 8.0 及以上（minSdk 26，targetSdk 34）
- 数据本地保存；只有导入/订阅网址时会联网下载你指定的 `.ics`，不上传任何数据

安装包：`吃药提醒-1.5.11.apk`（项目根目录）

产品介绍页：根目录的 `index.html`（网站首页），用浏览器打开即可查看功能、截图、隐私说明和下载按钮（页面依赖同目录的 `assets/` 截图和根目录的 APK）；网页版 .ics 日历生成器在 `web.html`。

## 一、安装

1. 把 `吃药提醒-1.5.10.apk` 传到手机（微信文件传输助手 / 数据线 / 网盘均可）。
2. 点击安装。系统提示「未知来源」时，允许对应的文件管理器或浏览器安装。
3. 打开「吃药提醒」。

> 新版会覆盖安装旧版并保留药品、账户和记录（versionCode 25）。首次安装如果被手机管家拦截，选择「继续安装」即可。

## 二、首次使用：把权限开全

App 首页如果出现黄色提示条「提醒权限未完全开启」，点「去设置」逐项开启；也可以到「设置」页的「权限状态」里逐项检查。

| 权限 | 作用 | 不开会怎样 |
| --- | --- | --- |
| 通知 | 显示闹钟通知 | 响铃时没有通知，部分系统会限制前台服务 |
| 精确闹钟（Android 12+） | 准点触发 | 系统可能把提醒推迟几分钟到几十分钟 |
| 显示在其他应用上层（悬浮窗） | 解锁使用手机、正在用别的应用时，直接弹出提醒卡片 | 解锁时只显示通知，需要点一下才进提醒页 |
| 后台运行 / 忽略电池优化 | 防止系统冻结 | 息屏久了可能不响 |
| 日历读写 | 写入系统日历 | 只能使用 App 内闹钟，不能同步日历 |
| 网络 | 网址导入 / 订阅刷新时使用 | 只能从本地文件导入 |

**锁屏或息屏时会自动点亮屏幕到锁屏，只响铃并显示通知，不会弹出整页卡片**；解锁使用手机、或正在用别的应用时，如果开启了「显示在其他应用上层（悬浮窗）」，才会自动弹出底部提醒卡片。1.5.10 打开 App 会引导开启悬浮窗；设置页「解锁时弹出提醒」可随时检查。

国产 ROM 额外建议（小米/红米、华为/荣耀、OPPO/一加、vivo）：
- 允许「自启动」「后台弹出界面」「锁屏显示」
- 电池 / 省电策略设为「不限制」
- 最近任务里给应用加锁，避免一键清理时被杀

**1.5.10 会在设置页增加「自启动 / 后台白名单」入口**，并按当前品牌给步骤；也会在首次打开时提醒一次。各品牌重点：
- **小米 / Redmi**：应用设置 → 应用管理 → 吃药提醒 → 自启动允许；省电策略「无限制」；权限 → 显示在其他应用上层。
- **华为（EMUI / HarmonyOS）**：应用和服务 → 应用启动管理 → 吃药提醒 → 关闭「自动管理」，手动允许「自启动 / 关联启动 / 后台活动」；电池 → 应用耗电管理允许后台活动；权限允许悬浮窗。
- **荣耀（MagicOS）**：应用和服务 → 应用启动管理 → 吃药提醒 → 关闭自动管理，允许自启动 / 关联启动 / 后台活动；电池 → 应用耗电管理允许后台活动；权限允许悬浮窗。
- 不同系统版本菜单名称会略有不同，找不到时可在「设置 → 应用 → 吃药提醒 → 权限」里逐项检查。

## 三、账户、导入与订阅

### 多账户（给家人分别用药）

一个账户 = 一个人（或一份独立的用药方案）。每个账户有**独立的药品、订阅链接、服药记录和系统日历**，导入或同步一个账户不会覆盖另一个账户。

- 今日 / 药品页顶部点「账户：名字 ▾」切换账户，列表只显示当前账户。
- 「设置 → 账户」可以添加、重命名、删除账户；删除只影响当前账户，至少保留一个。
- 新建账户后，先切到该账户，再导入它的 `.ics` 或设置它的订阅链接。
- 旧版本升级时会自动把原来的药品归入「我的药」账户，不会丢失。

> 每日服药时间（早/午/晚/睡前）是手机共用的四个时间点；不同账户的药会按各自方案落在这些时间点上。

### 导入用药方案

两种方式，导入/同步后都会覆盖**当前账户**的药品方案，并重排闹钟、更新当前账户的系统日历；其他账户不受影响。

**1）本地 .ics 文件**

「设置」→「从 .ics 文件导入」→ 选择手机里的 `.ics` 文件。

**2）从网址下载 .ics**

「设置」→「从网址导入 .ics」→ 粘贴链接 →「下载并导入」。

- 支持 `http://`、`https://` 和 `webcal://`（自动转成 https）
- 支持 301/302/307/308 跳转，最多 5 次
- 自动识别内容是否为日历文件；非 `.ics` 内容会提示「链接内容不是 .ics 日历文件」
- 下载上限 3 MB，连接超时 12 秒、读取超时 20 秒
- 成功导入后会记住链接，下次打开自动填好
- 下载成功后再让你确认，确认后才会覆盖当前账户的方案

### 网址订阅（每个账户各自更新）

如果 `.ics` 放在固定网址（Google 日历私密链接、医院/学校导出的日历等），切到对应账户，在「设置 → 网址订阅」里设置一次，之后自动刷新：

| 项目 | 说明 |
| --- | --- |
| 订阅链接 | 当前账户能直接下载 `.ics` 的地址；保存后立即同步一次 |
| 自动更新频率 | 手动 / 每 15 分钟 / 每 1 小时 / 每 4 小时 / 每 12 小时 |
| 立即同步 | 随时手动拉取当前账户的订阅 |

- 每个账户各自保存订阅链接和更新频率，多个账户的自动更新互不干扰。
- 每次同步先比对内容（SHA-256），只有内容变化才覆盖该账户方案并重排闹钟；名称和剂量相同的药保留原 id，已打勾的记录不丢。
- 自动更新用系统 WorkManager 调度，需要联网；系统省电/Doze 可能把 15 分钟的任务推迟，点「立即同步」不受影响。
- 订阅会覆盖该账户本地手动修改；如果主要靠手动编辑，建议频率设为「手动」。
- 订阅链接留空保存 = 取消该账户的订阅。
- 设置里会显示该账户上次同步时间和失败原因。

> 链接必须能**直接下载 .ics 内容**。网页版的分享页、需要登录的日历、网盘预览页都不行；Google 日历请用「以 iCal 格式下载」得到的 `basic.ics` 私密链接。

导入后回到「今日」，只显示**当前账户今天**的服药清单；未来几天不会铺在列表里，也不再显示“下一次提醒”卡片。

## 四、日常使用

### 今日
- 顶部标题固定为「请按时吃药」，下面是今天的日期和「账户：名字 ▾」切换入口。
- 今日页不显示「+」悬浮按钮；添加药品请到「药品」页点右下角「+」。
- **不再显示「下一次提醒」卡片，也不再把三类药放在一页里滚动**。标题下面固定是三个 tab：
  - **待服用（N）**：到点前后还能打勾的药，按计划时间排列。
  - **已服用（N）**：今天已经打勾的药，按计划时间排列。
  - **已过期（N）**：到点超过 1 小时仍未打勾的药，单独放在这里，整行置灰，不能补记。
  - 三个 tab 使用完全相同的行样式，都显示时间、时段、药名、用量和医嘱备注；**左右滑动列表或点 tab** 都可以切换。
- **点整行**可查看完整用药信息：日期时间、时段、用量、备注、账户，以及开始日期、服药时段、频率和结束方式。
- **点右侧「已服」**：这条立刻从「待服用」移到「已服用」；**点「撤销」**：从「已服用」移回「待服用」。
- **未到时间**：还没到点的药右侧显示「未到时间」，不能点击，防止提前打勾；到点后会自动变成可打勾。
- **已过期**：到点后超过 **1 小时**还没打勾，会从「待服用」移到「已过期」并置灰，不能再补记；点开详情也只能看，不能修改。已服用的记录撤销后，如果已经超过 1 小时，会直接进入「已过期」。
- **到点后还没吃的药会自动变成浅绿色背景**（主题色浅色），不用点「查看详情」也能看出来；打勾或超过 1 小时后恢复普通/置灰样式。
- 已服用的行会置灰、时间加删除线，但仍可在「已服用」里撤销。

### 药品
- 顶部同样可以切换账户；列表只显示当前账户的药。
- 右下角「+」添加药品：名称、用量、备注、服药时段（可多选）、开始日期、重复频率（按天/周/月）、间隔、结束方式（永不 / 到某天 / 共几次）。新药自动归入当前账户。
- 点药品进入编辑，底部可以删除。
- 修改保存后会自动重排闹钟，并按需更新当前账户的系统日历。

### 设置
- **账户**：当前账户、添加账户、重命名、删除；删除前会确认，只删当前账户。
- **每日服药时间**：早饭后 08:00、午饭后 12:30、晚饭后 18:30、晚上睡前 21:00，可改成自己的时间（所有账户共用）。
- **提前提醒**：准点响铃，或提前 5/10/15/30 分钟。
- **稍后提醒时长**：5/10/15/30 分钟。
- **测试闹钟**：5 秒后完整响一次；按 Home 键，或从最近任务里把 App 划掉，验证后台仍会响铃（解锁时弹出提醒卡片）。
- **解锁时弹出提醒**：授予「显示在其他应用上层」后，正在用手机时会从底部弹出提醒卡片；不开则只显示通知，点一下进入今日页。锁屏/息屏会自动点亮屏幕并只显示通知。
- **同步到系统日历**：为当前账户选择或创建专用日历；之后每次修改该账户药品会自动更新（可关闭）。
- **网址订阅**：当前账户的订阅链接、自动更新频率（手动 / 15 分钟 / 1 小时 / 4 小时 / 12 小时），以及「立即同步」。
- **导入 / 清除已服用记录**。

## 五、闹钟怎么响

到点后：

1. **锁屏/息屏时**：循环播放系统闹铃、震动，**自动点亮屏幕到锁屏**，并在锁屏通知栏显示「该吃药了」通知，**不自动弹窗**；点亮后可以直接看到通知，点通知进入详情。
2. **解锁使用手机时**：如果已开启悬浮窗，从屏幕**底部滑出提醒卡片**，同时循环播放系统闹铃、震动，持续 10 分钟或直到操作。卡片标题是「**该吃药了**」，下面显示计划时间和时段，再摘要列出这个钟点每种药的**名称和用量**。
3. 卡片底部只有两个按钮：
   - **查看详情**：关闭本次响铃，跳到「今日 → 待服用」，并把本次提醒相关的药行**用主题浅色（浅绿色）作背景高亮**；如果药属于其他账户，会自动切到那个账户。
   - **稍后提醒 N 分钟**：关闭本次响铃，N 分钟后再响一次；默认 10 分钟（设置里可改）。
4. 通知栏和卡片内容一致：标题「该吃药了」，内容是「计划时间 · 时段 + 药名 + 用量」的摘要，动作也是「查看详情」和「稍后提醒 N 分钟」；点通知正文同样进入今日待服用并高亮。
5. **上滑 / 下滑卡片、点卡片外面的暗色区域、按返回键**都会关闭本次提醒，但不会自动打勾；要记录「已服用」请点「查看详情」到今日页操作。
6. **同一钟点有多种药时**，卡片和通知会一次列出全部药，不会只显示其中一种。
7. **同一钟点有多个账户的药时**，也会合并在一个提醒里，摘要中药名前会带账户名（如「我的药 · 阿司匹林」）。
8. 卡片上的时间始终是**计划服药时间**，不是响铃那一刻或提前提醒的时间。
9. **从最近任务里划掉 App 不会取消已经排定的闹钟**（1.5.10 实测：划掉后到点仍会启动闹钟服务）。但如果在系统设置里点了「强行停止」，Android 会取消该应用的全部闹钟，只能重新打开 App 再排定；国产 ROM 的「一键清理 / 结束进程」如果等同于强行停止，也需要把 App 加入自启动/后台白名单。
10. **1.5.10 已去掉「后台闹钟守护」常驻通知**：小米实测完成自启动、省电无限制、悬浮窗等设置后，不必保留守护通知也能准时响铃；华为、荣耀按上面的启动管理设置即可。

> **关于弹窗**：1.5.10 起**锁屏/息屏会自动点亮屏幕到锁屏，只显示通知，不再自动弹窗**，避免锁屏上突然出现整页卡片。解锁使用手机、或正在用别的应用时，开启「显示在其他应用上层（悬浮窗）」才会自动弹出底部卡片；没开悬浮窗时只显示通知，点通知可进入今日页。设置页「解锁时弹出提醒」可检查悬浮窗状态。

> **关于准点**：1.5.10 沿用系统「闹钟」通道（`setAlarmClock`）排定，深度休眠或离开 App 后系统也会按闹钟优先级唤醒；闹钟服务被个别 ROM 拦截后台启动时还会自动重试。仍然建议在「设置 → 权限状态」把「后台运行 / 忽略电池优化」打开，并给国产 ROM 允许「自启动」「后台弹出界面」；否则系统省电策略仍可能冻结应用。

重启手机、修改系统时间、升级应用后，闹钟会自动重新排定。

## 六、系统日历

- 每个账户使用**自己的系统日历**：切到账户，设置 →「同步到系统日历」→「选择日历」→「创建专用本地日历」。
- 默认创建「吃药提醒 · 账户名」，例如「吃药提醒 · 爸爸」「吃药提醒 · 妈妈」；在系统日历 App 里可以分别显示/隐藏，不会混在一起。
- 已经分配给其他账户的日历不会出现在当前账户的选择列表里，避免两个账户写到同一个日历。
- App 会为每种药每个时段写入一条**每天重复**的日程（结束日期/次数会写成 RRULE），并带提前 5 分钟的日历提醒。
- 日历事件里包含账户名、药名、用量、时段和医嘱备注，事件备注末尾标注「由「吃药提醒」自动同步」。
- 之后在 App 里增删改药品，会自动重写**该账户**的日程（「自动同步」开关控制）。
- 「移除日历事件」只删除当前账户写入的日程，不动药品方案，也不影响其他账户。

## 七、数据与隐私

- 药品方案、服药记录、设置全部保存在本机 SharedPreferences。
- App 声明了网络权限，但只在导入 `.ics` 或刷新订阅时，向**你自己填写的那个链接**发起 GET 请求；不会上传药品、记录或任何使用数据。
- 不做统计、不接广告、没有云端账号体系；本地账户只用于把家人的药分开，不需要注册或登录。
- 卸载应用会清除本机数据；重新安装后需要再次导入方案。

## 八、自己编译

源码在 `android/`，需要 JDK 17 和 Android SDK 34：

```bat
cd android
set JAVA_HOME=C:\path\to\jdk-17
gradlew.bat assembleRelease
```

- 包名 / applicationId：`com.medremind.app`（debug 版后缀 `.debug`，可与正式版共存）
- 签名：使用本地 `app/medremind.keystore`，密码放在本地 `android/keystore.properties`（两者都已加入 `.gitignore`，不会提交；请单独备份，丢失后无法覆盖安装）
- 产物：`app/build/outputs/apk/release/app-release.apk`

> 项目路径包含中文时 Gradle 会警告，`gradle.properties` 里已经加了 `android.overridePathCheck=true`。

## 九、常见问题

**Q：到点没有响？**
按顺序检查：通知权限 → 精确闹钟 → 悬浮窗（解锁弹卡片）→ 电池优化 / 后台运行 → 国产 ROM 的自启动/后台限制。可以先用「测试闹钟」按 Home 或锁屏验证。

**Q：离开 App 后不准，甚至会晚几分钟？**
1.5.10 已经使用系统「闹钟」通道排定，正常情况会在设定时间立即唤醒；如果仍然晚，通常是手机省电策略把应用冻结了：
1. 打开 App 首页黄色提示条，把「后台运行」设为允许（忽略电池优化）；
2. 国产 ROM 再到系统设置里允许「自启动」「后台弹出界面」「锁屏显示」，省电策略设为「不限制」；
3. **从最近任务划掉不影响闹钟，不用特意保留**；但不要点系统设置里的「强行停止」，也不要用会“结束进程”的一键清理，这两种会取消已排定的闹钟；1.5.10 不再常驻通知，按品牌把自启动/后台活动开好即可；
4. 在「设置 → 权限状态」确认「精确闹钟」已开启，并确认「悬浮窗」已开启；开启后可以再用「测试闹钟」按 Home 键或从最近任务划掉验证一次。

**Q：响了但只有通知，没有底部提醒卡片？**
**锁屏/息屏时会自动点亮屏幕并只显示通知，这是 1.5.10 的设计**；解锁使用时，后台直接弹页面需要「显示在其他应用上层（悬浮窗）」。另外检查是否在「勿扰模式」，勿扰会压制横幅但闹钟声音通常仍会响。点通知里的「查看详情」也能进入今日页（锁屏时需先解锁）。

**Q：为什么测试闹钟会弹窗，真实提醒只有通知？**
测试闹钟是在 App 刚用过、屏幕解锁时触发的，系统允许直接弹页面；真实提醒如果发生在锁屏/息屏，1.5.10 会点亮屏幕到锁屏并只显示通知，不再弹窗。解锁使用手机时，要自动弹卡片仍需开启悬浮窗。

**Q：点通知后卡片闪一下就关了？**
刚弹出的 1.2 秒内会忽略返回事件（部分 ROM 在收起通知栏时会补发一次返回键），之后按返回、上滑/下滑卡片、点暗色区域都可以关闭。通知和卡片都只保留「查看详情 / 稍后提醒」两个动作；如果仍然只响通知，请确认「显示在其他应用上层（悬浮窗）」已开启（打开 App 会弹窗引导），并在国产 ROM 的权限管理里允许「后台弹出界面 / 显示在其他应用上层」。

**Q：闹钟显示的时间为什么和响铃时间不一样？**
页面和通知里的时间始终显示**计划服药时间**（例如早饭后 08:00）。如果设置了「提前提醒 5 分钟」，07:55 就会响，卡片上会写「提前 5 分钟 · 08:00 · 早饭后」，时间仍是 08:00；这是正常的，不是时间错乱。

**Q：从网址导入失败？**
- 确认链接在浏览器里打开就能直接下载 `.ics`（不是登录页、分享页、网盘预览页）；
- 服务器必须返回 200，403/404 会提示「服务器返回 HTTP 4xx」；
- 部分日历服务需要把私密链接里的 `https://` 换成 `webcal://`，App 会自动转换；
- 文件不能超过 3 MB；
- 公司/校园网可能需要代理，手机浏览器能打开而 App 打不开时，先确认网络环境。

**Q：怎么给家人分别导入？**
1. 「设置 → 账户 → 添加账户」，输入名字（如「爸爸」）；
2. 确认当前账户已切到这个人；
3. 用「从 .ics 文件导入」「从网址导入」或「网址订阅」导入他的方案。
每个账户的药品、订阅和日历都是独立的，导入第二份不会覆盖第一份。

**Q：导入第二份 .ics 会不会把第一份覆盖掉？**
不会。导入/同步只替换**当前账户**的药品，其他账户保持不变；订阅也一样，每个账户各有一个链接。

**Q：系统日历里怎么区分不同账户？**
每个账户第一次同步时会创建自己的本地日历，名字是「吃药提醒 · 账户名」。在系统日历 App 的日历列表里可以分别显示/隐藏；它们不是同一个日历里的混排事件。

**Q：两个账户同一时间吃药，会响两次吗？**
不会。只要钟点相同，无论同一时段还是不同时段被设成同一时间，都会在同一个提醒里合并显示，药品名称前带账户名，避免两个提醒互相覆盖；点「查看详情」会切到对应账户并高亮这一钟点的药，在今日页逐个打勾即可。如果希望分开，把两个人的服药时间设成不同钟点即可。

**Q：订阅没有按 15 分钟更新？**
Android 的周期任务（WorkManager）最小间隔是 15 分钟，且系统在省电/Doze 状态下会推迟执行；这是系统限制，不是 App 出错。需要立刻更新时点「立即同步」。设置页会显示当前账户上次同步时间和失败原因。

**Q：日历里没有事件？**
确认已授予日历读写权限，切到对应账户，并在设置里点一次「重新同步」。部分机型没有可写日历，选择「创建专用本地日历」即可。

**Q：删除账户会删掉什么？**
只删除当前账户的药品、服药记录、订阅和日历事件；其他账户不受影响。至少会保留一个账户。

**Q：换了手机/重装怎么恢复？**
把之前导出的 `.ics` 用「从 .ics 文件导入」导入；也可以把 `.ics` 放到任意可访问的网址，用「从网址导入」或「网址订阅」恢复。

**Q：为什么没有云同步？**
服药数据敏感，App 不主动上传任何数据；需要备份时导出/保存 `.ics` 即可。
